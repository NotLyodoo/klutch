Politique de confidentialité de Klutch

En vigueur depuis le 9 novembre 2026

En bref : Klutch fonctionne sur l'ordinateur de son utilisateur. Toutes les données restent sur cet ordinateur. Rien n'est vendu, partagé ni envoyé à un serveur de Klutch, qui n'en a pas.

Qui est responsable

Klutch est un logiciel personnel créé et utilisé par Lyodoo, streamer Twitch, pour publier les clips de ses lives sur son propre compte TikTok.

La transcription des sous-titres est faite sur l'ordinateur de l'utilisateur, sans service externe.

Ce que Klutch envoie

  • À TikTok : uniquement les vidéos validées par l'utilisateur, avec la description qu'il a choisie.
  • À Discord : si l'utilisateur l'active, un message sur son propre serveur indiquant que des clips sont prêts.

Aucune donnée n'est vendue, louée ni utilisée pour de la publicité.

Durée de conservation

Les données restent sur l'ordinateur jusqu'à ce que l'utilisateur les supprime dans Klutch, ou supprime le dossier de l'application.

Tes choix

  • Déconnecter TikTok dans les réglages de Klutch supprime les jetons d'accès de l'ordinateur.
  • L'accès peut aussi être retiré à tout moment depuis les paramètres du compte TikTok.

Privacy Policy (English)

In short. Klutch runs on its user's own computer. All data stays on that computer. Nothing is sold, shared, or sent to any Klutch server; there is none.

Data used. TikTok username (to show the connected account); TikTok access tokens (to post approved videos); the list and statistics of posted videos (views, likes, comments, shares, shown in the app); recordings of the user's own Twitch streams and public chat messages (to find highlights). All of it is stored locally. Captions are transcribed locally, without any external service.

What Klutch sends. To TikTok: only videos the user approved, with the caption the user chose. To Discord, if enabled: a message on the user's own server saying clips are ready. No data is sold, rented, or used for advertising.

Retention and choices. Data stays on the computer until the user deletes it. Disconnecting TikTok in Klutch's settings deletes the access tokens; access can also be revoked anytime in TikTok's account settings.

Contact. Lyodoo, via twitch.tv/lyodoo.
